# المعايير التقنية الإلزامية — ZHR MASTER M.GRAPHIC PROMPT TEMP

## 1. محرك الرندرة المجزأة (Chunked Rendering Engine)

لتفادي بطء أو انهيار الرندرة عند التعامل مع مشاهد معقدة ثلاثية الأبعاد أو ريلز سريعة، يتبع النظام البنية التالية:

```text
[Project Root]
├── vo/audio_preflight.wav      # مسار الصوت بعد المعالجة والفحص المسبق
├── scenes/
│   ├── scene_01.js             # كود المشهد الأول المستقل
│   ├── scene_02.js             # كود المشهد الثاني المستقل
│   └── ...
├── renders/
│   ├── chunks/
│   │   ├── scene_01.mp4        # رندرة المشهد 1 (60fps)
│   │   ├── scene_02.mp4        # رندرة المشهد 2 (60fps)
│   │   └── ...
│   ├── preview/
│   │   └── contact.png         # لوحة الاتصال والمعاينة للاعتماد الفوري
│   └── final_output.mp4        # التجميع النهائي الخالي من الفقدان (Lossless Concat)
```

### خوارزمية الاستئناف الذكي (Resumable Rendering Logic):
- إذا وُجد `scene_01.mp4` وكان كود المشهد ومصدره لم يتغير، يتم تخطيه آلياً واستئناف رندرة المشهد التالي مباشرة.
- عند تعديل معطيات مشهد محدد (مثل كولاج أو كاميرا 3D في المشهد 3)، يُعاد بناء ورندرة `scene_03.mp4` فقط، ثم يُعاد الدمج النهائي في ثانيتين فقط عبر FFmpeg:
<div dir="ltr" style="text-align: left;">

```bash
ffmpeg -f concat -safe 0 -i chunks_list.txt -c copy final_output.mp4
```
</div>

## 2. بروتوكول فحص الصوت والارتباط البصري (Audio Pre-flight & Micro-Sync)

- **الفحص الأوتوماتيكي لملف الصوت:**
  - التحقق من التردد: لا يقل عن `44100 Hz`.
  - معالجة مستوى الصوت المستهدف: `-14 LUFS` إلى `-16 LUFS` لتوافق منصات البث والسوشيال ميديا.
  - استخراج توقيت الكلمات بالمللي ثانية عبر Whisper وحفظها في `timeline.json`.
- **التوافق الحركي الإلزامي:**
  - الكشيدة الحركية (*Dynamic Kashida*): لا تُمدد عشوائياً، بل ترتبط بلحظات السكون (Pauses) أو التشديد الصوتي.
  - ضربات الانتقال (Beat Drops): تُحدد مسبقاً في ملف السكريبت وتُربط بأوامر الانتقال الزمني لكل مشهد.

## 3. بوابة الاعتماد الإلزامية (The Strict Approval Gate)

لا يُسمح بأي حال من الأحوال بإنتاج أو تصدير الفيديو قبل استيفاء الشروط التالية:
1. توليد لقطة ثابتة من كل مشهد وتجميعها في لوحة `contact.png`.
2. تقديم ملخص مكتوب يتضمن: نوع الموشن، الأبعاد، أسلوب حركة الكاميرا، ومدة كل مشهد.
3. انتظار اعتماد المستخدم الصريح قبل تشغيل محرك الرندرة الكامل.
